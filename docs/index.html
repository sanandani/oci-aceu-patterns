OCI ACE-U Patterns

A verifiable portfolio of OCI, Oracle Database, and Java examples, including a runnable ACE-U trust service and a read-only OCI posture scanner. The trust scores demonstrate a research implementation; they are not a validated assessment of real people.

Architecture

Quickstart

Requires Java 21, Maven, and Docker Compose. The demo uses synthetic profiles, performs six REST calls, and prints the database audit trail.

git clone https://github.com/sanandani/oci-aceu-patterns.git
cd oci-aceu-patterns
./scripts/demo.sh
# stop and remove the local database volume:
docker compose down -v
