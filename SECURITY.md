# Security policy

This repository contains synthetic profiles and placeholder OCI identifiers only. Never use real people's profile data in the demo. Do not commit credentials, OCI config files, wallets, `.env` files, Terraform state, or real profile exports.

The scanner is read-only. Review IAM findings in context before making changes. The Terraform examples are instructional and may create billable resources; inspect a plan and supply local credentials/values before applying. The default Vault secret is a placeholder, not an operational credential.

Report a vulnerability through a private GitHub security advisory for this repository. Include reproduction details without sharing credentials or personal data.
